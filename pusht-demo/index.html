图例

圆盘 = 智能体（agent，你控制它 / 策略控制它） 灰色 T 块 = 要推动的物体（block） 绿色虚线 = 目标位姿（goal，位置 + 朝向）

对应 LeRobot 概念

观测 observation = 圆盘位置 + 图像/状态；动作 action = 圆盘每一步往哪移。

真实 LeRobot 就是采一批人类演示（lerobot-record），让策略学「看到这画面 → 该往哪推」，这就是行为克隆 / 模仿学习。

训练后的策略用 lerobot-eval --env.type=pusht 在 gym_pusht（pymunk 2D 物理）里评测，本页就是那个任务的简化版。
